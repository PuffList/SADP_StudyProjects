# Реализация структур данных и базовых алгоритмов сортировки на C++

Проект содержит реализации основных структур данных и алгоритмов сортировки, написанные на языке C++.

## Структуры данных

Реализованы следующие структуры данных:
- Связный список (LinkedList)
- Стек (Stack)
- Очередь (Queue)
- Хеш-таблица (HashTable)
- Двоичное дерево поиска (BST)
  и другие

## Алгоритмы сортировки

Реализованы базовые алгоритмы сортировки:
- Сортировка пузырьком (Bubble Sort)
- Сортировка вставками (Insertion Sort)
- Сортировка выбором (Selection Sort)
- Быстрая сортировка (Quick Sort)
- Сортировка слиянием (Merge Sort)
- Пирамидальная сортировка (Heap Sort)

## Требования

Для компиляции и запуска необходим:
- Компилятор C++ (g++ или clang++)
